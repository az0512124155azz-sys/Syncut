# Put Syncut on GitHub

1. Create an empty GitHub repository named `Syncut`.
2. Upload **all files and folders from this package** to the repository root.
3. Make sure the default branch is `main`.
4. Open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.
5. Open the **Actions** tab and run `Windows native alpha` manually for the first test build.
6. If the build succeeds, download `Syncut-Alpha-Windows` from the workflow run's Artifacts section.

Normal users should download the built artifact/release only; they do not need Visual Studio, MSYS2 or other developer tools.
