Syncut הוא ממשק חדש לעורך וידאו מקצועי, עם Timeline מלא, אודיו, אפקטים, צבע, כתוביות וכלי AI אופציונליים. המטרה: לשמור על העומק של תוכנת NLE מקצועית — בלי הממשק הצפוף והמיושן.

הקבצים ל־GitHubאיך מתקינים נכון

כלים מקצועיים — בלי להעמיס הכול על המסך

העיצוב החדש מציג כלים לפי ההקשר וחלל העבודה, אבל לא מוותר על יכולות מקצועיות.

V

Timeline מקצועי

מסלולי וידאו, אודיו וכתוביות, Ripple, Slip, Split, Keyframes, Markers, Proxy ו־Time Remap.

FX

אפקטים וצבע

Effect Stack, מסכות, Rotoscope, LUTs, Color scopes, Stabilization ו־Scene Cut.

A

אודיו

ייבוא MP3/WAV/FLAC, Mixer, meters, fade, normalization, filters וספריית סאונדים מקוונת.

CC

כתוביות

עריכת כתוביות, SRT/VTT/ASS, תזמון, תרגום ויצירה אוטומטית מעברית ואנגלית.

T

Titles ותבניות

כותרות, lower thirds, גרפיקה ותבניות שניתן לייצר ולשמור לשימוש חוזר.

⇧

Render וייצוא

פריסטים, Render Queue, Proxy/Transcode, OTIO וייצוא לפורמטים מקצועיים.

AI הוא אופציה — לא משקל חובה

Syncut צריך לזהות קודם אם כבר קיים מנוע AI מקומי. אם אין — המשתמש יכול להמשיך בלי AI. אין הורדה כבדה אוטומטית.

זיהויבודק runtime קיים לפני כל התקנה או הורדה.
בחירהAI כבוי כברירת מחדל; המשתמש מחליט אם להפעיל.
Ctrl+Shift+Zפותח את עוזר Syncut רק כאשר חיבור AI זמין.
Agent לעריכההעוזר מתכנן ומבצע פעולות דרך פקודות אמיתיות של העורך, עם Undo ואישור לפעולות משמעותיות.

זרימת שפה

בקשה בעברית → תרגום פנימי לאנגלית בעת הצורך → מודל AI → תשובה → תרגום בחזרה לעברית. קבצי תמונה, מסמכים ותסריטים יכולים להיכלל כהקשר.

Hebrew prompt → translation layer → AI model → tool plan → Syncut actions → Hebrew response

FFmpeg אינו AI. הוא מנוע עיבוד מדיה שבו Syncut יכול להשתמש לביצוע פעולות כמו המרה, פילטרים, ניתוח אודיו/וידאו וייצוא.

כתוביות אוטומטיות בעברית ובאנגלית

המערכת מתוכננת ל־Whisper/Vosk עם עברית ואנגלית כמצבים ראשיים, לא כתוספת צדדית.

עברית

RTL אוטומטי, פיסוק, חלוקת משפטים, תיקון חפיפות והגבלת שורות.

English

LTR, punctuation, timing cleanup, speaker-aware segmentation and export.

ייצוא

SRT, VTT, ASS, תרגום כתוביות ובדיקת שגיאות לפני הייצוא.

איך ההתקנה אמורה לעבוד

למשתמש רגיל אסור להיות צורך ב־Visual Studio, MSYS2, KDE Craft או כלי build אחרים.

היעד: GitHub Actions בונה מראש את Syncut על שרת Windows. המשתמש מוריד Installer מוכן ומתקין רק את האפליקציה וה־runtime שנדרש לה.
GitHub CIמקמפל את קוד C++/Qt/MLT מחוץ למחשב המשתמש.
Artifactנוצר Windows package/installer אמיתי.
התקנההמשתמש מתקין את Syncut בלבד. AI נשאר אופציונלי.

מה נמצא בחבילת GitHub

החבילה כוללת את קוד המקור של Syncut, האתר הזה, מסמכי הארכיטקטורה, תיעוד Windows ו־GitHub Actions.

קוד מקור

fork של בסיס Kdenlive עם מיתוג Syncut ורכיבי Syncut הראשונים.

GitHub Actions

workflow ל־Windows שמריץ build בענן ומעלה ZIP כ־artifact.

GitHub Pages

workflow שמעלה את תיקיית website כאתר הפרויקט.

Syncut הוא פרויקט עצמאי המבוסס על רכיבי קוד פתוח. יש לשמור הודעות זכויות יוצרים ורישיונות של Kdenlive, KDE, MLT, FFmpeg ושאר התלויות בהתאם לרישיונות שלהם.
